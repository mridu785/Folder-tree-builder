📦 Mobile Project Builder Pro

Reliable project-tree parser, structure verification, and ZIP creation—all local and offline.

Supports standard tree output, Unicode branches, dotfiles (like .gitignore), extensionless files (like _redirects), and plain relative paths. Unsafe paths (../ or absolute paths) are blocked. No source code contents are generated.

The ZIP contains an explicit root project folder, every detected subfolder, and every detected file. The ZIP is checked for entry count before download.

Android workflow
  1. Save this HTML and open it in your browser.
  2. Paste the full project tree.
  3. Tap Analyze & verify, review the complete list.
  4. Build ZIP and download.
  5. Extract the ZIP in your file manager.
  6. Open the project in your code editor and fill the files.
